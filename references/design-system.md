# 配色与视觉规则

## 证据等级

**采样值**：读取 Muse 官方公开 PNG 中的非透明像素；证明该图中使用了这些像素颜色，不证明源码 token 名称或所有版本一致。**建议值**：为网站和 app 复现整体感受而选择，允许随字号、密度、设备调整。当前参考范围是浅色桌面界面；没有验证 Muse 深色模式。

## 核心配色

| Token | 值 | 来源等级 | 用法 |
|---|---|---|---|
| `--muse-bg` | `#FCFCFC` | 采样：Ideas、Activity | 大面积页面底色 |
| `--muse-surface` | `#FFFFFF` | 采样：批准卡、Activity | 输入框、菜单、弹层、浮动控件 |
| `--muse-soft` | `#F3F4F5` | 采样：Activity、批准卡 | 次级按钮、分段控件底、状态容器 |
| `--muse-text` | `#111112` | 采样：Ideas、批准卡 | 标题、正文、主要图标 |
| `--muse-muted` | `#67696C` | 采样：Ideas | 摘要、说明、时间；保持可读性 |
| `--muse-border` | `#E3E3E3` | 采样：公开图边缘 | 装饰分隔和非必要边界 |
| `--muse-primary` | `#0064D4` | 采样：批准卡 Allow 按钮 | 主要操作、文字链接、焦点 |
| `--muse-on-primary` | `#FFFFFF` | 建议：语义映射 | 主要按钮上的文字；品牌色变亮时重新选择 |
| `--muse-primary-hover` | `#0058BD` | 建议 | 蓝色按钮悬停 |
| `--muse-primary-soft` | `#E8F2FF` | 建议 | 轻量选中底色，不承担普通文字颜色 |
| `--muse-control-border` | `#828589` | 建议 | 输入框等必须可辨识的控件边界 |
| `--muse-success` / `--muse-success-soft` | `#237A39` / `#EAF5EC` | 建议 | 完成、已连接；配文字/图标 |
| `--muse-danger` / `--muse-danger-soft` | `#B42318` / `#FFF0EE` | 建议 | 错误、破坏性操作；配文字/图标 |

`#FFFFFF`、`#FCFCFC`、`#F3F4F5` 的差别很小，应结合空间和必要的阴影建立层级。不要无限降低文字对比来追求“高级灰”。线框图标可以使用正文或次要文字颜色。

**颜色分工**：大背景和绝大部分组件保持中性；蓝色只负责可识别的交互重点；绿色、红色只用于状态。每个操作组通常只有一个高强调动作。已有品牌色被用户要求保留时，以该色代替 primary，同时派生 primary-hover、primary-soft、on-primary 与焦点色，并重新检查对比，保留其他结构规则。不能只换按钮默认色而让悬停又变回蓝色。品牌色很浅时，按钮文字可能需用深色；文字链接和焦点也可能需要更深的品牌变体。

**避免误读**：角色的奶油色、插图的植物绿不是整站主题色。观察截图中的紫色屏幕共享提示是系统控件，不纳入 Muse 品牌色。商家预览、嵌入网页、图表和生成内容的颜色属于内容，不纳入应用调色板。

## 字体与空间（建议起点）

使用平台无衬线字体；中文回退到 PingFang SC / Microsoft YaHei / Noto Sans CJK SC。未核实 Muse 的具体字体文件，不宣称是某一付费字体。

| 层级 | 建议值 | 使用 |
|---|---|---|
| 正文 | `16px / 1.65`，400 | 中文阅读、摘要 |
| 辅助信息 | `13–14px / 1.5`，400 | 时间、分类；不要承担唯一关键说明 |
| 条目标题 | `18–20px / 1.4`，500–600 | 项目、文章、任务标题 |
| 页面标题 | `32–44px / 1.15`，600 | 用 clamp 响应尺寸，不挤占首屏 |

间距以 `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px` 形成节奏。元素内部紧凑，组与组之间更宽。阅读列约 `640–760px`；带列表或展示内容的主区域约 `960–1120px`。以内容决定宽度，避免照搬 2× 截图的物理像素值。

## 形状和表面（建议起点）

- 胶囊按钮：`999px`；普通媒体：`12px`；菜单：`20px`；大面板：`28px`。内嵌圆角应考虑外部圆角和内边距，不能所有层都取同一个值。
- 紧凑图标按钮可用 `44–48px` 圆角方形，圆角约 `14–16px`；等宽高的 `999px` 胶囊表现为圆形。悬停后显露的功能名使用圆角矩形或胶囊标签，与按钮属于同一套形状语言。图标默认隐藏视觉文字，状态细则见 interaction.md。
- 触控按钮常用最小高度 `44px`，桌面可按密度缩小视觉形状，但保留合适命中区域。
- 轻悬浮：`0 2px 6px rgba(17,17,18,.04), 0 10px 28px rgba(17,17,18,.06)`。
- 弹层：`0 8px 24px rgba(17,17,18,.08), 0 24px 64px rgba(17,17,18,.10)`。
- 内容列表默认无阴影；不要在每层叠加阴影。轻微顶部渐隐可以保留固定工具栏的可读性，但不遮挡可交互内容。
- 禁用样式单独设计，不能把整个父容器透明化而使可读内容变灰；禁用动作需有原因时，提供文字说明。

## 图片和图标

用一个统一角色或少量有材质感的小物件提供温度。优先使用用户自己的照片、植物、研究对象和已授权素材。网站已有高质量摄影时不强制加吉祥物。不要复制 Muse 角色或品牌标记。

导航与功能图标保持一致笔画、尺寸和光学重量；可使用项目已有图标库。桌面图标导航需有名称或提示，移动端常用入口保留文字。图表保留科学语义色和图例，不因套风格破坏数据区分。

## 深色和高密度界面

若项目已有深色模式，应保留并用语义 token 适配；明确它是本项目的扩展，而不是实测 Muse 深色复刻。重新检查文字、边界、阴影和状态对比。对于表格、编辑器和科研工具，保留必要密度；将柔和风格用于外壳、筛选和详情，不扩大每个数据单元。
