# 色彩、层级、留白与形状：实测（v1.5）

排版见 [typography.md](typography.md)，动效见 [motion.md](motion.md)。这份管颜色系统、阴影、模糊、圆角、密度与栅格。

## 证据等级

**实测值**：2026-11-06 读取 `platform.muse.ai` 自己提供的三个 CSS chunk 中声明的 `--ai-gray-*` / `--blue-*` / `--red-*` 等色阶、`--shadow-elevation-*`、`--fill-*`、`--spacing-density` / `--radius-density`、`squircle` 规则。对比度是用 WCAG 2.x 相对亮度公式算的，半透明色先与背景合成——`scripts/check_tokens.py` 会复算一遍。

## 中性色是半透明的

这是整套配色的地基，也是最容易抄错的一条。

| 用途 | token | 值 | 白底 |
|---|---|---|---|
| 主要文字 | `ai-gray-1100` | `#111112` | 18.9:1 |
| 次要文字 | `ai-gray-a650` | `#00040996` | 5.3:1 |
| 三级文字 | `ai-gray-a600` | `#00040b8f` | 4.8:1 |
| 分隔线 | `black-a100` | `#0000001a` | — |
| 悬停 wash | `black-a75` | `#00000013` | — |
| 弹窗遮罩 | `black-a100`（深色下 `black-a500`） | — | — |

注意这些 alpha 近黑**带一点蓝**（`#000409`、`#00040b`），不是纯黑降透明度。这让灰字在白底上不显脏，又能和 `#111112` 的标题同族。

实色中性色（`ai-gray-025 #fafafa` → `ai-gray-1100 #111112`）仍然存在，用于**背景与填充**；**文字和描边用 alpha 档**。原因：同一个 token 落在白底、`#F3F4F5` 面板、淡蓝提示条上，视觉权重不变；实色灰换个底就偏了。

深色模式是结构相同的另一组：`ai-gray-dark-a*` 是**半透明近白**（如 `#f3f8ff96`）。不要把浅色值搬过去，也不要用 `opacity` 整体压暗。

## 每个色相只有一个"可用档"

Muse 的每个彩色色相都有 050 / 500 / 650 / 700 几档，但**界面上真正用的是 650**。原因看对比度就清楚了——650 这一档被调到**既能当白底上的文字，又能当白字下面的填充**（两者是同一个色对，所以同一个数）：

| 色相 | 650 | 白底 | `#FCFCFC` | `#F3F4F5` | 可用性 |
|---|---|---|---|---|---|
| blue | `#0064D4` | 5.57 | 5.42 | 5.05 | ✅ 主动作 |
| purple | `#8523C6` | 6.88 | 6.70 | 6.25 | ✅ |
| red | `#C01F37` | 6.01 | 5.86 | 5.46 | ✅ 危险 |
| indigo | `#4553E4` | 5.82 | 5.67 | 5.28 | ✅ |
| pink | `#C62385` | 5.28 | 5.14 | 4.79 | ✅ |
| green | `#008200` | 5.01 | 4.88 | 4.55 | ✅ 成功（灰面板上只剩 4.55，别再往上叠透明度） |
| orange | `#C65323` | 4.50 | 4.39 | **4.09** | ⚠️ 白底刚好压线，**灰面板上不达 AA** |
| yellow | `#B07C00` | **3.67** | 3.57 | 3.33 | ❌ 任何底都不能承载文字 |

规则：

- **橙与黄不承载文字，也不做白字按钮的底。** 要用它们表达状态，就画成点、条、色块，把含义写在旁边的正文色文字里。`scripts/check_tokens.py` 把这两条写成了断言。
- 其余色相可以直接当文字色、链接色、按钮底。
- 淡底（050 档）配同色 650 文字仍在 4.5:1 以上（blue 5.06、red 5.39、green 4.60），所以"淡色胶囊 + 同色文字"是安全的。

## 主色是一个 token，不是一套配色

实测：产品页把整站主色收在 `--platform-accent` 一个变量上，由根节点的 `[data-accent]` 切换（blue/red/purple/green/orange/pink/indigo 等），其余全是中性色。

对应到本仓库：

```html
<body class="muse-theme" data-muse-accent="indigo">
```

**不要给每个区块分配一种鲜艳颜色。** 一个页面一个主色，语义色（成功/危险/警告）另算，其余靠中性色和留白分层。

## 阴影：三档，带文字色调

```
elevation-0  none
elevation-1  0 2px 8px 0 #11111214, 0 2px 16px 0 #1111120a
elevation-2  0 4px 12px 0 #1111121f, 0 6px 24px 0 #11111214
elevation-3  0 6px 16px 0 #11111229, 0 8px 32px 0 #1111121f
```

- **两层**：一层近距离定义边缘，一层远距离给体积。单层阴影要么太硬要么太糊。
- **染的是 `#111112`（正文近黑），不是纯黑。** 纯黑阴影在暖白页面上会发灰发脏。
- **只有三档。** 不要为每个组件调一个新阴影。内容卡片用 `#F3F4F5` 实底、**无边框无阴影**；阴影留给真正浮起来的东西（浮动控件、菜单、弹窗）。

## 模糊是"材质"，不是一个 blur 值

实测有四档半透明填充（ultrathin / thin / regular / thick），它们与 `backdrop-filter: blur()` 配合使用——**填充决定透出多少，blur 决定糊到什么程度**：

```css
.muse-material {                      /* 无 backdrop-filter 支持时退回不透明底 */
  background: var(--muse-material-regular);     /* #ffffffb3 */
  backdrop-filter: blur(24px) saturate(1.8);
}
```

`saturate()` 不能省：只做模糊，底下的彩色会被洗成灰。做玻璃层时必须验证**最坏情况**——底下是一张高对比度图片时，上面的文字还达不达 4.5:1。达不到就加厚填充，而不是加大模糊。

## 圆角：密度 + 超椭圆

实测圆角是 1–38px 的整数档乘一个密度系数，并且有 `corner-shape: squircle` 的渐进增强：

```css
.muse-squircle { border-radius: var(--r); }
@supports (corner-shape: squircle) {
  .muse-squircle { corner-shape: squircle; border-radius: calc(var(--r) * 2); }
}
```

超椭圆需要**约两倍**的半径才读起来和普通圆角一样大。不支持的浏览器拿到普通圆角，不做任何额外处理。

## 密度：一个属性重调整个界面

实测的三档（`data-style` / `data-radius-theme`）：

| 档 | 间距系数 | 圆角系数 |
|---|---|---|
| dense / tight | 0.875 | **0.5** |
| default / normal | 1 | 1 |
| airy / soft | 1.125 | **1.2** |

所有间距和圆角都写成 `calc(base * var(--density))`，于是整块界面可以用一个属性换密度。注意**圆角的变化幅度远大于间距**（0.5 ↔ 1.2 vs 0.875 ↔ 1.125）：密集界面要的是更方，不只是更挤。

本仓库：

```html
<main data-muse-density="dense">   <!-- 数据表、工具面板 -->
<section data-muse-density="airy"> <!-- 落地页 -->
```

胶囊按钮不参与圆角缩放——胶囊在任何密度下都是胶囊。

## 留白与栅格

- 间距基数 **4px**，乘密度系数。实际用到的档：4 / 8 / 12 / 14 / 16 / 20 / 24 / 28 / 40 / 48 / 50 / 60 / 64 / 80。
- 落地页区块上下内边距实测 **100–128px**（营销页 80px）。区块之间是整宽 1px 分隔线，不是外框。
- **版面宽、文字窄**：页面容器 1440（内容 1280），而正文列限宽到 415–832px。这是"大气但好读"的来源——放宽容器的同时必须限制文字列宽，否则只是行长失控。
- 导语约 46rem，正文约 68ch，中文约 38em。

## 图形与图片

- 媒体圆角分级：常规图 24px，大视频/横幅 32px，整宽品牌横幅 42px。**图片本身不设圆角，由容器 `overflow: hidden` 裁切**，这样换图不用改样式。
- 图片放在 `#F3F4F5` 容器里，加载前后都不会出现白洞。
- 图标统一线性风格、`currentColor` 描边；用 `data:` URI 画图标会把颜色写死，深色模式下必然对比不足。
- 个性集中在少量物件/人物/插画上，功能图标保持中性。

## 交付前检查

- 文字与实际背景 ≥ 4.5:1（半透明色按合成后算）；有意义的控件边界 ≥ 3:1。
- 玻璃层在最坏背景下仍达标。
- 页面只有一个主色；橙/黄没有承载文字。
- 阴影只用三档之一；内容卡片没有阴影。
- 一处改密度属性，整块间距和圆角一起变，没有残留的硬编码 px。
- 容器变宽时文字列没有跟着变宽。
