# 页面层：Muse 营销页实测（v1.2，v1.3 补充组件）

> **v1.4 更正：排版以 [typography.md](typography.md) 为准。** 本文件测的是营销页
> `ai.meta.com/muse`；用户实际对比的产品页 `platform.muse.ai` 用的是另一套值——
> 主要文字 `#111112`（不是 `#0A1317`）、次要文字半透明 `#00040996`（不是实色
> `#5D6C7B`）、动作蓝 `#0064D4`（不是 `#0457CB`）、页面底 `#FCFCFC` 与 `#F3F4F5`
> 交替（不是纯白）。本文件下面"实测排版"一节的字号阶梯（64/48/36/28/24/18/16/14）
> 和"展开项标题 300 字重"**不要再照用**：300 在 Muse 的字体里不存在，营销页那条
> 声明实际渲染成 400；真用一个有 300 的字体会得到 Muse 从未显示过的发虚标题。
> 版式、组件、区块节奏部分仍然有效。

v1.1 的颜色来自 Muse **应用界面**截图。个人网站、研究主页、产品介绍页更接近 Muse 的**官方产品页** <https://ai.meta.com/muse/>。本文件记录该页面的实测排版与版式，作为网页的默认参考。

## 证据等级

**实测值**：2026-11-05 用无头 Chrome 打开官方页面，在 1440×900 与 390×844 两种视口逐段滚动，读取 `getComputedStyle` 与元素尺寸。证明该日期、该页面的渲染结果，不证明 Meta 内部 token 名称或其他页面一致。**建议值**：为个人网站改写的映射。页面使用 Meta 专有字体 Optimistic，**不要**下载或分发该字体。

## 实测排版

| 层级 | 字号 / 行高 | 字重 | 颜色 | 实例 |
|---|---|---|---|---|
| 首屏大标题 | 64 / 74px | 500 | 白（压在视频上） | Hero 标题 |
| 特写标题 | 48 / 56px | 500 | `#0A1317` | 横向内容区标题 |
| 区块标题 | 36 / 46px | 500 | `#0A1317` | “Take the busywork off your plate” |
| 卡片标题 | 28 / 34px | 500 | `#0A1317` | 安全卡片标题 |
| 展开项标题 | 24 / 30px | **300** | `#0A1317` | 手风琴标题；问答标题更粗 |
| 导语 | 18 / 26px，或 24 / 30px 300 | 400 / 300 | `#5D6C7B` | 区块标题下的说明 |
| 正文 | 16 / 24px | 400 | `#5D6C7B`（说明）或 `#0A1317`（卡片正文） | 展开项内容 |
| 眉标 | 14 / 20px，全大写，字距 −0.01em | 400 | `#0457CB` | “MUSE FEATURES” |

要点：**大标题不用 600/700**，用 500；展开项标题甚至用 300。层级靠字号差（64→48→36→28→24→18→16→14）建立，不靠加粗。中文无大写，可以保留蓝色和字号，略增字距（0.02–0.04em）。

## 实测版式

- **宽内容区**：1440 视口下内容宽 1376px（左右各 32px）。文字列另行限制：导语约 814px，展开项正文约 480–520px。即“版面宽、文字窄”。
- **区块节奏**：区块上下内边距 80px；大区块之间用**整宽** 1px `#DADDE1` 线分隔，而不是卡片阴影。
- **区块头**：眉标 → 36px 标题 → 18px 导语，左对齐；主按钮（胶囊）放在同一行最右，与标题顶部对齐。
- **展开列表 + 配图**：左列是手风琴（每项上方 1px 线，标题 24px/300，右侧 +/− 图标），右列是大圆角配图（664×664，圆角 24px），随展开项切换。窄屏改为“标题 → 图 → 左右翻页”。
- **特性卡片**：两列，卡片底 `#F1F4F7`，圆角 24px，内边距约 24px，无边框无阴影；圆形图标 + 28px 标题 + 16px 正文。
- **媒体圆角分级**：常规图 24px，大视频/大横幅 32px，整宽品牌横幅 42px。图片本身不设圆角，由容器裁切。
- **按钮**：全部胶囊（`border-radius: 100px`）。尺寸 40（导航）/ 44（常规）/ 52（区块主按钮）；内边距 8–14 × 22–30px；文字粗体约 16px。次级动作是“圆圈箭头 + 蓝色文字链接”（Learn more），不是灰色按钮。
- **导航**：纯文字链接，悬停出现 32px 高、24px 圆角的浅底；右侧只有一个蓝色主按钮。
- **问答**：整宽手风琴，问题约 28px/500，每行 1px 分隔，右侧 + 图标。
- **首屏**：整屏视频或图，居中白色大标题，行内可嵌一个线性图标（如礼物）。
- **轮播区**：整段 `#F6F6F6` 底，左侧固定的标题列（眉标/48px 标题/导语/按钮），右侧横向滚动的竖幅卡片（圆角 32px），卡片下方是“粗体姓名 + 说明”的图注。

## 迁移到个人网站与科研工具

| 官网做法 | 个人/科研站的对应 |
|---|---|
| 宽版面、窄文字 | 内容区放宽到约 1280–1376px，正文与导语各自限宽（~44rem / 52rem） |
| 整宽细线分区 | 用 `border-top: 1px solid` 分开页面大区块，取消区块外框 |
| 眉标 + 500 字重标题 | 每个区块标题前加蓝色眉标；标题统一 500 |
| 手风琴 + 配图 | 研究方向、履历、方法步骤：标题列表展开说明，配图随之切换 |
| 灰底无边框卡片 | 少量需要成组的内容（联系方式、特性、工具面板）用 `#F1F4F7` 圆角 24 无边框 |
| 胶囊主按钮 + 圆圈箭头链接 | 每组一个蓝色主按钮；其余用“圆圈箭头 + 文字”链接 |
| 问答手风琴 | 工具页的“使用说明 / 方法与验证 / 常见问题” |

### 科研工具页（高密度界面）

- 页头不要装进大卡片：返回链接 → 眉标（类别）→ 48px 标题 → 18px 导语 → 状态行（成熟度、版本、验证）→ 右侧主按钮/教程链接。
- 工作区面板：`#F1F4F7` 底、24px 圆角、无边框；面板内输入框用白底与可辨识的控件边框（`#828589` 级别），这样灰底卡片里白色输入框自然突出。
- 主动作统一为蓝色胶囊；不要黑色按钮。破坏性或次级动作用灰底胶囊或文字链接。
- 表格、图表、画布保持原有密度与科学配色，只统一外壳、圆角和字体。
- 状态与说明（验证范围、局限）放在可展开的“方法与验证”里，默认收起，标题行写清结论。

## 不要做

- 不要使用或分发 Optimistic 字体；改用站点已有或开源的几何无衬线字体，并保持 500/300 的字重关系。
- 不要复制官网视频、人物、吉祥物或 Meta 标志。
- 不要把每个区块都装进卡片；官网的大部分内容直接放在白底上。
- 不要把展开项标题加粗到 600；轻字重标题 + 细分隔线才是这种安静感的来源。

## v1.3：在研究网站上验证过的组件

以下组件在一个双语科研个人网站（首页、简历、15 个浏览器科研工具、教程）上落地并经截图核对，作为可复用实现收进 `assets/muse.css`，完整样例见 [tool-example.html](../assets/tool-example.html)。

| 组件 | 类名 | 规则 |
|---|---|---|
| 两栏首屏 | `.muse-hero` `.muse-hero-media` | 左：眉标 → h1（全页唯一）→ 18px 导语 → 一个蓝色大胶囊 + 两个圆圈箭头链接；右：`#F1F4F7` 32px 圆角面板放一个物件或标志。860px 以下单栏，面板限宽。不要在首屏堆标签、状态行和多个同级按钮 |
| 教程按钮 | `.muse-guide` | 所有工具页同一个样式：浅蓝胶囊 + 书本图标，悬停/聚焦时**书本由合上变为翻开**（图形变化，文字常显），按下变实心蓝。教程页对应的「打开工具」用蓝色胶囊 + 前移箭头（`.muse-button-forward`），二者成对出现 |
| 工具外壳 | `.muse-tool-head` `.muse-back` `.muse-status-line` | 页头不装进卡片：返回（左向折角）→ 眉标（类别）→ 48px 名称 → 导语 → 状态行（成熟度、版本、验证日期）；右侧只放教程按钮与真正的页面级动作，下方一条细线后是工作区 |
| 验证说明 | `.muse-details` | 方法与验证细节收进「How it was validated / 验证方法」展开行（+/−），默认收起；状态行本身给出结论 |
| 工作区面板 | `.muse-tool-panel` | `#F1F4F7` 无边框 24px 圆角，面板内输入框保持白底和可辨识边框；次级按钮在灰面板上变**白色**胶囊，否则会与面板融为一体；禁用按钮用更深一级的灰底 + 次要文字色，不用整体透明 |

### 命名一致

同一个工具在卡片、工具页标题、教程标题、侧栏与正文中只用**一个名字**（中英各一）。不要“卡片用短名、页面用长名、教程再起一个名”。在数据层只保留一个名字字段，教程页标题直接读它。

### 深色模式下的图片化图标

用 `data:` SVG 画的箭头、折角会把颜色写死（例如 `stroke='%230457CB'`），深色模式下对比不足。要么改用 `currentColor` 的内联 SVG 或 `mask`，要么为深色主题提供一份浅蓝版本（如 `#5EA3FF`）。

### 防退化

若项目用 stylelint 限制字重或禁止大写，需同步：允许眉标 `text-transform: uppercase`、展开项标题 300、主胶囊 700，以及标题字重变量（如 `var(--ds-weight-heading)`）。
