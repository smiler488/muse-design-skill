# 排版：platform.muse.ai 实测字体系统（v1.4）

这是本技能的**排版单一来源**。涉及任何有文字的界面，先读这份，再读 [design-system.md](design-system.md) 或 [product-page.md](product-page.md)。

## 证据等级

**实测值**：2026-11-06 在 1440×900 用无头 Chromium 打开 <https://platform.muse.ai/>，读取 `getComputedStyle`，并下载该页自己提供的三个 CSS chunk，直接读出其中的 `--text-*`、`--ai-gray-*`、`--blue-*` 变量定义。所以下表不是从截图反推的近似值，而是页面声明的 token 本身。证明该日期该页面的值，不证明 Meta 内部命名或其他页面一致。页面字体 `optimisticAI` 为 Meta 专有，**不要下载或分发**。

**建议值**：字体替代方案、CJK 规则、大写字距，下面逐条标注。

v1.2 的 [product-page.md](product-page.md) 测的是另一个页面（营销页 `ai.meta.com/muse`）。两者不一致的地方以本文件为准，差异见最后一节。

## 字号阶梯（实测）

行高是**固定 px，不是倍数**；而且**字号越大，行高比例越紧**。

| 角色 | 字号 / 行高 | 比例 | 字重档 | 用途 |
|---|---|---|---|---|
| `caption-2` | 11 / 13 | 1.18 | 400 / 500 / 600 | 角标、计数 |
| `caption-1` | 12 / 16 | 1.33 | 400 / 600 | 标签、Tab |
| `footnote` | 13 / 18 | 1.38 | 400 / 500 / 600 | 状态行、脚注 |
| `subheadline` | 14 / 20 | 1.43 | 400 / 500 / 600 | 次级标签、眉标（眉标用 `--muse-weight-eyebrow`，默认 600） |
| `subheadline-large` | 15 / 20 | 1.33 | 400 / 500 | 导航链接、表单标签 |
| `body` | 16 / 22 | **1.375** | 400 / 500 / 600 | 正文、按钮 |
| `response` | 16 / 26 | 1.63 | 400 / 500 / 600 | **长文阅读**（唯一放松行高的角色） |
| `body-status` | 17 / 22 | 1.29 | 400 / 500 / 600 | 说明段、主按钮文字 |
| `title-3` | 18 / 26 | 1.44 | 400 / 500 / 600 | 卡片标题、导语 |
| `title-2` | 22 / 28 | 1.27 | 500 | 展开项标题 |
| `title-1` | 30 / 34 | **1.13** | 400 / 500 / 600 | 区块标题 |
| `lg-title-3` | 34 / 40 | 1.18 | 400 / 500 / 600 | 窄屏首屏标题 |
| `lg-title-2` | 40 / 46 | 1.15 | 400 / 500 / 600 | 首屏标题（桌面实测值） |
| `lg-title-1` | 48 / 52 | **1.08** | 400 / 500 / 600 | 最大常规标题 |
| `landing-display` | 34→47→48→62 | 1.1 | 500 | 落地页首屏，按断点换档 |

落地页大标题的四档实测值：`<640px` 34/40 · `≥640px` 47/52 · `≥768px` 48/56 · `≥1024px` 62.445/1.1。

阶梯之间**没有中间值**。需要比 30px 更响的区块标题时，跳到 40/46，不要调成 36px，也不要加粗。

## 字重（实测）

页面提供的字体只有两段：`font-weight: 400 600`（可变字体）与一个 400 斜体。token 里只出现三档：

```
--font-weight-normal: 400      普通正文
--font-weight-medium: 500      标题、按钮、导航、强调标签（"-medium"）
--font-weight-semibold: 600    行内强调、表头（"-emphasized"）
```

**300 在 Muse 的字体里不存在。** 营销页 CSS 写了 `font-weight: 300` 的展开项标题，但字体只有 400–600，浏览器把它钳到 400 渲染。如果你换成一个真有 300 的字体（Hanken Grotesk、Inter 都有），就会得到一个 Muse 从未显示过的、发虚的标题。**不要用 300，也不要用 700/800。**

## 字距（实测）

```
--tracking-normal: 0em                全部 ≤34px 的文字
--tracking-platform-hero: -.6px       40px 首屏标题（= -0.015em）
landing-display letter-spacing: -.01em 落地页大标题
```

也就是：**40px 以下一律不收字距**。给 18–30px 的标题加 −0.01em/−0.02em 会把字挤在一起，是最容易把"克制"做成"糊"的一步。

**建议值（本技能覆盖实测值）**：全大写眉标用 **+0.06em 正字距**。营销页的大写眉标实测是 −0.01em，但 14px 全大写需要正字距才站得住，而 platform.muse.ai 根本不用大写眉标。

## 颜色（实测）

文字色是**半透明近黑**，不是实色灰：这样同一个 token 落在白底、`#F3F4F5` 面板、淡蓝底上，关系都不变。

| 用途 | token | 值 | 白底对比度 |
|---|---|---|---|
| 主要文字 | `ai-gray-1100` | `#111112` | 18.9:1 |
| 次要文字 | `ai-gray-a650` | `#00040996`（≈ rgba(0,4,9,.588)） | 5.3:1 |
| 三级文字 | `ai-gray-a600` | `#00040b8f` | 4.8:1 |
| 装饰（非文字） | `ai-gray-a100` | `#000c1e17` | 分隔线 |
| 动作蓝 | `blue-650` | `#0064D4` | 5.6:1 |
| 悬停蓝 | `blue-700` | `#0058BE` | 6.7:1 |
| 页面底 | `bg-primary` | `#FCFCFC` | — |
| 交替区底 | `bg-secondary` | `#F3F4F5`（`ai-gray-050`） | — |

交叉验证：`a650` 叠在 `#FCFCFC` 上合成出 `#68696B`，正是 v1.1 从应用截图里采样到的 `#67696C`。两条独立证据对上了。

深色模式用同一套结构的另一组 token：`ai-gray-dark-a*` 是**半透明近白**（如 `--ai-gray-dark-a500: #f3f8ff96`）。不要把浅色的 `#00040996` 直接搬过去，也不要用 `opacity` 整体压暗一个浅色值。

Muse 自己的 `tertiary`（`ai-gray-a400`）对白底只有 **2.5:1**，不达 AA。本技能不把它作为文字色提供；`--muse-text-quaternary` 仅用于占位符形状、禁用填充这类不承载信息的地方。

## 字体与回退（建议值）

`optimisticAI` 是 Meta 专有，不要使用。页面自己的回退写法值得照搬：一个 `local("Arial")` 的度量兜底 face，避免字体加载前后跳动。

替代字体选几何无衬线、x 高度大、字形接近单线的：**Hanken Grotesk**（可变 300–800，Google Fonts）、**Inter**、**Figtree**。本仓库 `assets/muse.css` 默认用 Hanken Grotesk。

```css
--muse-font-sans: "Hanken Grotesk", "Inter", system-ui, -apple-system, ...;
-webkit-font-smoothing: antialiased;   /* 页面自己也设了这一条 */
-moz-osx-font-smoothing: grayscale;
```

**不要只写系统字体栈就收工。** `-apple-system, "Segoe UI", "Microsoft YaHei"` 在 macOS 上是 SF、在 Windows 上是 Segoe UI、在 Linux 上是别的东西——三种骨架、三种 x 高度，"Muse 感"里属于字体的那一半直接没了。这是实际改造中最常见的退化。

## CJK（建议值，Muse 页面没有中文）

- **行高放宽**：16/22 用在汉字上太挤。正文用 16/26（`response`），标题行高不低于 1.3。
- **字距归零**：汉字字身框本来就满，再加 −0.015em 会贴在一起。`lang="zh"` 的标题一律 `letter-spacing: 0`。
- **字重**：中文字体常只有 400/500/700。宁可用 500 当标题、400 当正文，也不要靠 700；没有 500 时用 400 配更大字号，而不是跳到 700。
- **行宽**：中文一行 30–40 字（约 38em）比 68ch 舒服。

## 常见退化（这些就是"看起来差一截"的来源）

| 症状 | 实际写了什么 | 改成 |
|---|---|---|
| 正文松散、整页发飘 | `line-height: 1.6` / `1.65` | `16/22`；长文才用 `16/26` |
| 标题糊、字挤在一起 | 每级标题都 `-0.01em`～`-0.025em` | ≤34px 字距 0；只有 40px+ 用 −0.015em |
| 标题"用力"但不高级 | `font-weight: 600`/`700` | 500；需要更响就加大字号 |
| 轻标题发虚 | `font-weight: 300` | 400 |
| 层级靠猜 | 36px / 26px / 19px 这类自定字号 | 阶梯上的 40 / 30 / 22 / 18 |
| 灰字在灰卡上变脏 | 实色 `#5D6C7B` | 半透明 `#00040996` |
| 字体没有性格 | 只有系统字体栈 | 真的加载一个几何无衬线 |
| 主按钮像促销 | `font-weight: 700` | 17/22、字重 500 |
| 大写眉标挤成一团 | `text-transform: uppercase` + 负字距 | +0.06em |

## 与 product-page.md（营销页）的差异

| 次要文字 | `#5D6C7B` 实色 | `#00040996` 半透明 | 半透明 |
